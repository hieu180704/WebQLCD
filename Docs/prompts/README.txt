# THƯ VIỆN PROMPT TÁI SỬ DỤNG NHANH

# Mục lục
1. [Mục Đích]
2. [Quy Ước Đặt Tên]
3. [Danh Mục Hiện Có]

---

# 1. Mục Đích
Nơi lưu các mẫu câu lệnh và kịch bản prompt dùng lại nhiều lần, để không phải
gõ lại mô tả dài mỗi phiên làm việc.

---

# 2. Quy Ước Đặt Tên
- Định dạng: `<động-từ>-<đối-tượng>.txt` — ví dụ `review-chuong-truyen.txt`,
  `soan-bao-cao-tuan.txt`.
- Mỗi file mở đầu bằng 1 dòng mô tả prompt đó dùng khi nào.
- Prompt dùng chung cho mọi dự án thì để ở đây; prompt gắn với một phân vùng
  cụ thể thì để cạnh phân vùng đó trong `Docs/SourceOfTruth/<Domain>/`.

---
