# 4. Lưu Ý Cho Người Tiếp Quản
- Git Bash trên Windows: gpg-agent không mở được socket khi `GNUPGHOME` có đường dẫn dài (lỗi "socket name ... is too long"); tạo key test bằng `GNUPGHOME=$(mktemp -d)`. `backup.sh` không cần agent (`--recipient-file`).
- psql trên Windows mặc định client encoding WIN1252, vỡ thông báo tiếng Việt; `verify-restore.sql` đặt `\encoding UTF8`.
- Chưa có lịch chạy: cron nằm trong compose ở lát 5b.
