# 2. Đã Làm & Kiểm Chứng
- `output: "standalone"`; Dockerfile 2 target (`app` chạy `server.js`, `migrate`); stage build đặt `DATABASE_URL` giả vì `next build` import `client.ts` (ném lỗi khi thiếu biến) mà không truy vấn.
- `scripts/migrate.mjs`: migrator runtime của drizzle-orm bằng role sở hữu, rồi cấp quyền role runtime (thu UPDATE/DELETE/TRUNCATE sổ két, audit). Chạy lại được.
- Compose: `db` (init tạo 2 role), `migrate`, `app`, `caddy` (TLS), `backup` (vòng lặp hằng đêm: `backup.sh` + `cleanup.sql`).
- `advanced.ipAddress`: không đổi code. Đã thử chỉ tin `x-real-ip` thì 2 e2e khoá IP hỏng (chạy không proxy không ai đặt header), hoàn tác. Next tự đặt `x-forwarded-for` chỉ khi chưa có (`base-server.js:567`) nên app trần bị giả IP; sau Caddy thì header được đặt lại.
- Kiểm chứng:
  - PG local, role runtime riêng: e2e 35/35; role runtime bị chặn UPDATE/DELETE sổ két, audit, ALTER TABLE, CREATE TABLE.
  - Docker Desktop: build 3 image, `up` đủ 5 service, HTTPS qua Caddy (CSP nonce, HSTS, http→https 308), đăng ký + đăng nhập (cookie `__Secure-`, HttpOnly), `X-Forwarded-For` giả bị bỏ qua, sao lưu `--now`, khôi phục + đối soát + đổi tên DB + đăng nhập lại.
  - Lint, typecheck, `npm test` 177, e2e 35; prettier (`--print-width 140`) trên `scripts/migrate.mjs`, `docker-compose.yml`.
