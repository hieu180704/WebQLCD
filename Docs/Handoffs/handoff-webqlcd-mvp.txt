# 4. Auth Đã Làm (4c)
- Code: `src/shared/infrastructure/auth/` (auth, login-throttle, password, access, guard), module `identity` (port Authenticator, SignIn/SignOut, server action, form), trang `/dang-nhap`, UI shadcn ở `src/shared/ui/`.
- Khác thiết kế đã duyệt: khoá IP không dùng rate limit gốc của Better Auth (chỉ chạy qua HTTP router, server action gọi `auth.api` bỏ qua). Cả IP và tài khoản đếm ở hook + `login_throttles`; tài khoản sai 5 lần khoá 15 phút, IP sai 20 lần/15 phút khoá 15 phút; không mount `/api/auth`. Lý do: `Docs/Decisions/2026-10-20-login-throttle.txt`.
- Guard `requireSession({ role?, write? })` gọi ở đầu server action / trang (presentation lấy qua `composition-root.ts`), không gọi trong application.
- Rủi ro còn: khoá theo tài khoản có thể bị lạm dụng để khoá chủ tiệm (DoS); 15 phút chỉnh được ở `THROTTLE_RULES`.
